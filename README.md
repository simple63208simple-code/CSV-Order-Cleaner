# CSV Order Cleaner

Python-программа для обработки таблиц с заказами.

## Возможности

- Чтение CSV-файлов
- Проверка обязательных столбцов
- Поиск повторяющихся записей
- Проверка неправильных и пустых значений
- Подсчёт выручки
- Создание очищенного CSV
- Сохранение ошибочных записей
- Формирование текстового отчёта

## Запуск

1. Установите Python 3.
2. Поместите CSV-файл в папку проекта.
3. Запустите main.py.
4. Введите название CSV-файла.

## Результат

Программа создаёт три файла:

- clean_orders.csv
- invalid_orders.csv
- report.txt
